# Python 并发模型全景图（2026版）

## 1. 多线程 (threading)

- **适用场景**：IO 密集型（网络、文件、数据库）
- **优点**：简单、共享内存
- **缺点**：受 GIL 限制，CPU 密集型几乎无加速
- **推荐指数**：★★☆☆☆

## 2. 多进程 (multiprocessing)

- **适用场景**：CPU 密集型计算
- **优点**：绕过 GIL，每个进程独立解释器
- **缺点**：内存占用高、进程间通信成本高
- **推荐指数**：★★★★☆

## 3. 异步编程 (asyncio)

- **适用场景**：高并发 IO（Web 服务、爬虫、聊天服务）
- **优点**：单线程高并发、资源占用低
- **缺点**：学习曲线陡峭，不能用于 CPU 密集任务
- **推荐指数**：★★★★★（现代 Python 首选）

## 4. 其他高级方案

- **concurrent.futures**：线程池 / 进程池高级封装
- **Celery**：分布式任务队列
- **Ray / Dask**：分布式计算框架
- **FastAPI + Uvicorn**：异步 Web 服务最佳实践

## 选择指南

| 场景               | 推荐方案          |
|--------------------|-------------------|
| Web API / Agent    | Asyncio + FastAPI |
| CPU 密集计算       | 多进程            |
| 高并发网络请求     | Asyncio           |
| 简单并行任务       | concurrent.futures|
| 大规模分布式任务   | Ray / Celery      |

**核心结论**：
**现代 Python 开发 = 异步思维 + 合理多进程补充**
